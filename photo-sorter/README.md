# 📸 PhotoSorter

행사에서 찍은 **여러 명의 여러 장** 사진을 넣으면, **얼굴 인식**으로 같은 사람끼리 자동으로 묶어 **인물별 폴더**를 만들어 주는 데스크톱 앱입니다.

- 🖥️ Electron 기반 데스크톱 앱 (Windows / macOS / Linux)
- 🔒 **완전 오프라인** — 사진이 외부로 전송되지 않고 모든 처리가 내 컴퓨터 안에서 이루어집니다.
- 🧠 [face-api.js](https://github.com/vladmandic/face-api) 모델(얼굴 검출 + 128차원 얼굴 특징 + 군집화) 사용

---

## 동작 방식

1. **사진 불러오기** — 파일 여러 개 선택하거나 폴더째로 추가 (드래그 & 드롭도 지원)
2. **얼굴 검출** — 각 사진에서 모든 얼굴을 찾습니다.
3. **특징 추출** — 얼굴마다 128차원 숫자 지문(descriptor)을 만듭니다.
4. **군집화** — 지문이 비슷한 얼굴끼리 묶습니다. 이름을 미리 몰라도 "같은 사람" 그룹이 자동 생성됩니다.
5. **이름 붙이기(선택)** — 각 그룹의 이름을 직접 수정할 수 있습니다.
6. **내보내기** — 선택한 폴더 아래 `PhotoSorter_결과/<인물이름>/` 으로 사진을 복사합니다.
   - 한 사진에 여러 명이 있으면 각 인물 폴더에 **모두** 복사됩니다.
   - 얼굴이 검출되지 않은 사진은 `_미분류/` 폴더로 모입니다.

## 실행 방법

> Node.js 18 이상이 필요합니다.

```bash
cd photo-sorter
npm install      # electron 등 의존성 설치
npm start        # 앱 실행
```

### 설치 파일(.exe / .dmg / .AppImage) 만들기

```bash
npm run dist
```

`dist/` 폴더에 각 OS용 설치 파일이 생성됩니다.

## 프로젝트 구조

```
photo-sorter/
├── main.js                  # Electron 메인 프로세스 (창, 로컬 정적 서버, 파일 IPC)
├── preload.js               # 렌더러에 노출하는 안전한 API 브리지
├── renderer/
│   ├── index.html           # UI 마크업
│   ├── style.css            # 스타일
│   ├── renderer.js          # 검출 · 군집화 · 렌더링 · 내보내기 로직
│   └── vendor/face-api.js   # 얼굴 인식 라이브러리 (오프라인 번들)
├── models/                  # 얼굴 인식 모델 가중치 (오프라인 포함)
│   ├── ssd_mobilenetv1_*    # 얼굴 검출
│   ├── face_landmark_68_*   # 얼굴 정렬용 랜드마크
│   └── face_recognition_*   # 128차원 특징 추출
└── package.json
```

## 참고 사항 / 한계

- 옆모습·역광·아주 작게 찍힌 얼굴은 검출이 어려울 수 있습니다. 결과는 **사람이 확인 후 이름 수정**하는 것을 전제로 합니다.
- 군집 기준값(`MATCH_THRESHOLD`)은 `renderer/renderer.js` 상단에서 조정할 수 있습니다.
  - 값이 **낮을수록** 더 엄격하게(그룹이 많아지고 잘못 합쳐지는 일이 줄어듦), **높을수록** 관대하게 묶입니다. 기본값 `0.5`.
- 큰 사진은 검출 속도를 위해 긴 변 기준 `1024px`로 축소해 분석합니다(원본 파일은 그대로 복사됨).
